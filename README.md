# Employee Attrition Analytics Dashboard

## Overview
Interactive machine learning dashboard for analyzing and predicting employee attrition using Python and Streamlit.

## Features
- Employee attrition prediction
- Interactive visualizations
- Random Forest machine learning model
- Real-time prediction probability
- Attrition trend analysis

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Plotly
- Streamlit
- Git & GitHub

## Dataset
IBM HR Analytics Employee Attrition Dataset
